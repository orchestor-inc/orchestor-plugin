# 改善事項の優先順位付け

ユーザーリクエスト: $ARGUMENTS

## 事前確認

このプラグインの `skills/` ディレクトリ下にある該当する SKILL.md ファイルを読んでください。
対象のワークスペースを確認し、承認されたデータのみを使用してください。

## 手順

orchestor-cli、orchestor-reports を読んでください。ブランド、日付範囲、および競合のスコープを確定してください。確認されたギャップの背後にある回答および引用元を調査してください。エビデンスおよび測定可能なフォローアップにそれぞれ紐づけられた、最大 3 つの優先順位付きアクションを返してください。観察されたギャップと仮説を区別してください。合意されたアクションを Orchestor Issues として保存するよう求められた場合にのみ orchestor-manage-issues を使用してください。GitHub Issues は作成しないでください。

## 返却内容

スコープ、結果、根拠、および未解決の制限事項を明記してください。
