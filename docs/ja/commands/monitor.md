# モニタリングの設定

ユーザーリクエスト: $ARGUMENTS

## 事前確認

このプラグインの `skills/` ディレクトリ下にある該当する SKILL.md ファイルを読んでください。
対象のワークスペースを確認し、承認されたデータのみを使用してください。

## 手順

orchestor-cli、orchestor-prompts を読んでください。ワークスペース、正確な質問、および要求された設定を特定してください。作成する前に、一致する既存のプロンプトがないか確認してください。ユーザーが明示的にモニタリングまたは実行を要求しない限り、下書きを作成してください。無関係な設定は保持してください。プロンプトを読み戻し、その ID と状態を返してください。orchestor-runs は、明示的に要求された測定にのみ使用してください。

## 返却内容

スコープ、結果、根拠、および未解決の制限事項を明記してください。
