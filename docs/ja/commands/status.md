# 接続ステータス

ユーザーリクエスト: $ARGUMENTS

## 事前確認

このプラグインの `skills/` ディレクトリ下にある該当する SKILL.md ファイルを読んでください。
対象のワークスペースを確認し、承認されたデータのみを使用してください。

## 手順

orchestor-cli を読んでください。`orc --version` と `orc status` を実行してください。認証の診断が必要な場合にのみ `orc auth status` を使用してください。認証情報の値を含めずに、ワークスペースと接続ステータスを報告してください。設定の変更や測定の開始は行わないでください。CLI が見つからない場合は、https://orchestor.io/docs/cli へのリンクを提供してください。

## 返却内容

スコープ、結果、根拠、および未解決の制限事項を明記してください。
