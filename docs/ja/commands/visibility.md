# ビジビリティの比較

ユーザーリクエスト: $ARGUMENTS

## 事前確認

このプラグインの `skills/` ディレクトリ下にある該当する SKILL.md ファイルを読んでください。
対象のワークスペースを確認し、承認されたデータのみを使用してください。

## 手順

orchestor-cli と orchestor-reports を読んでください。必要に応じて、アイデンティティには orchestor-brands、保存された文章には orchestor-answers、引用された URL には orchestor-sources を使用してください。要求されたブランドと比較期間を特定してください。すべての比較において、同じプラットフォーム、国、およびプロンプトスコープを使用してください。レポートを取得し、最も大きな差異の背後にある保存された回答を調査してください。比較表、回答 ID または引用元 URL、および制限事項を返してください。要求されない限り、新しい測定をリクエストしないでください。

## 返却内容

スコープ、結果、根拠、および未解決の制限事項を明記してください。
