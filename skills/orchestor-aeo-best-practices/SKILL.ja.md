# AEO 分析のベストプラクティス

証拠を結論やアクションに移す前に、これらのルールを適用してください。構成は Vercel や Supabase の焦点を絞ったルールファイルによる優先度ベースのガイダンスに従っており、ここでのドメインルールは Orchestor 分析について説明しています。

## 適用するタイミング

- ブランドを競合他社と比較する場合、または期間を比較する場合。
- visibility/引用の変化を説明する場合、または改善の優先順位を決定する場合。
- レポート、定性的なアノテーション、または提案されたモニタリングアクションをレビューする場合。
- 保存された AI 回答と外部調査を組み合わせる場合。

## 使用方法

タスクに関連するルールのみをお読みください。各ルールには、失敗モード、誤ったアプローチ、正しいアプローチ、およびその実用上の限界が含まれています。1 つの参照先で判断に対処できる場合は、すべての参照先をロードしないでください。

CLI 作業の場合は、接続とワークスペースを確認し、不慣れなリーフヘルプを確認してください。MCP の場合は、公開されているツールのスキーマを確認してください。いかなるルールも認可を上書きしたり、インストールによってデータアクセス権が付与されたりすることはありません。

## レビュー手順

1. 主張、要求されたアクション、および使用された証拠を特定します。
2. 結論を評価する前に、スコープとメトリクスの意味を確認します。
3. 主張をその回答、ソース、または収集レシートまで追跡します。
4. カバレッジの欠落と代替となる説明を確認します。
5. 修正された結論、または次に必要な範囲を限定した証拠のリクエストを返します。

## 返却内容

どの結論が裏付けられているか、どれが仮説のままであるか、および具体的にどのような証拠やスコープの変更が必要かを明記してください。言葉遣いよりも実質的な誤りを優先してください。効果量、ベンチマーク結果、または信頼度スコアを捏造しないでください。
