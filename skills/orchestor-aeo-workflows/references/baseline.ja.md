# ベースライン評価

1. 管理対象のブランド Web サイト、対象ワークスペース、比較ブランド、対象の質問、チャネル、およびロケールを確認してください。代理店の場合は、クライアントの Web サイトを使用してください。
2. 既存のブランド／プロンプト設定と保存された観測結果を検査してください。ユーザーがオンボーディングを要求した場合は、レビュー済みのオンボーディングフローを使用し、ユーザーの編集内容を保持してください。
3. 指定された期間のビジビリティとサイテーションを読み取り、代表的な保存済みの回答とソースを検査してください。観測結果のない設定済みプロンプトはギャップです。
4. 利用可能な分母、欠落データ、およびそれぞれエビデンスに紐づく最大 3 つの優先順位付きネクストアクションとともにベースラインを返してください。
5. 新規の測定が要求された場合は、実行する前に対象を限定したプロンプト／チャネルのセットを定義してください。黙ってモニタリングを有効にしたり、単発の収集を使用したりしないでください。

**不適切:** ブランドレコードを作成した後にセットアップ完了と呼び、あたかも観測されたかのようにサンプルレポートの行を表示する。

**適切:** 設定の完了、承認された測定、利用可能な回答、および使用可能なベースラインを区別する。エビデンスがまだ利用できない場合は、捏造されたパフォーマンス数値ではなく、その状態と具体的な次のステップを返す。
