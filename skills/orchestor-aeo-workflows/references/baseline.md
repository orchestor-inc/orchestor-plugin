# Baseline assessment

1. Confirm the managed brand website, intended workspace, comparison brands,
   target questions, channels, and locale. For an agency, use the client's website.
2. Inspect existing brand/prompt configuration and saved observations. If the user
   requests onboarding, use the reviewed onboarding flow and preserve their edits.
3. Read visibility and citations for a declared period; inspect representative
   saved answers and sources. A configured prompt without observations is a gap.
4. Return the baseline with available denominators, missing data, and at most three
   prioritized next actions, each tied to evidence.
5. If new measurement is requested, define the bounded prompt/channel set before
   executing it. Do not silently enable monitoring or use one-shot collection.

**Incorrect:** call setup complete after creating a brand record and then show
sample report rows as if they were observed.

**Correct:** distinguish configuration completion, accepted measurement, available
answers, and a usable baseline. If evidence is not yet available, return that
state and the specific next step, not invented performance numbers.
