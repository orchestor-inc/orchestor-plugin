# コンテンツ改善サイクル

1. 対象の正確なページ、ユーザーの質問、および観測されたサイテーション／回答のギャップを特定してください。
2. 現在のページと関連する引用エビデンスを読み取ります。タイトルや検索スニペットからその内容を推測しないでください。
3. 具体的な変更を提案してください: どの主張、セクション、エンティティの説明、またはエビデンスを変更すべきか、そしてそれがなぜ観測されたニーズに対処するのかを示します。
4. 事実の正確性とオーナーの文体を維持してください。推薦文、顧客、統計、製品機能、または第三者による推奨を捏造しないでください。
5. 編集が要求された場合は、ユーザーが利用可能なコンテンツツールを通じてレビュー可能なドラフトを作成してください。Orchestor の分析結果単体は、公開の許可にはなりません。
6. 公開先とコンテンツが承認されている場合にのみ公開してください。何が変更されたかを記録してください。
7. フォローアップの測定が要求された場合は、同一のコホートを比較し、交絡因子を開示してください。前後の差異だけでは因果関係の証明にはなりません。

**不適切:** 普遍的なコンテンツの法則を約束したり、ページが引用されやすくなるように根拠のない事実を追加したりする。

**適切:** エビデンスに裏付けられた変更を行い、どのような観測結果が仮説を支持、否定、または未解決のままにするかを定義する。
