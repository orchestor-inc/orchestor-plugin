# エージェント向けウェブサイトの評価

技術的な観察結果を用いて、エージェントが公開ウェブサイト上で発見、読み取り、または実行できる内容を説明します。スキャンスコアは、AEO パフォーマンスやコンバージョンの証明ではありません。

## 開始する前に

対象となる公開ドメインと、ユーザーが要求しているのが保存されたレポート、新規スキャン、検証、またはブラウザージャーニーのいずれであるかを確認します。ワークスペースと接続が判明している必要があります。新規スキャン／ジャーニーはネットワーク処理を実行する可能性があるため、質問の内容を満たせる場合は既存のエビデンスを優先してください。

## クイックスタート

```bash
orc agentic-web scans create --help
orc agentic-web sites reports list --help
orc agentic-web checks list --help
```

リクエストを作成する前に、サポートされているフィールドと URL 制約を検査してください。対応する読み取りまたは書き込みを見つけるには、[コマンドファミリー](references/commands.ja.md) を使用します。

## 手順

1. 正確なサイトと要求された成果を特定します。
2. 利用可能な場合は関連する保存済みレポートを読み取り、その観察日時を記録します。
3. 新規スキャンが必要な場合は、必要な場合にのみブラウザエビデンスを選択し、サポートされている公開 URL を使用します。明示的な MCP エンドポイントはサイト URL とは区別して保持してください。
4. レポートを取得し、失敗したチェックをそのエビデンスとともに検査します。
5. そのエビデンスによって裏付けられる最小限のサイト変更を提案します。要求されない限り、サイトの編集や公開を行わないでください。
6. 要求された変更を行った後、同じチェックまたはジャーニーを検証し、エビデンスを比較します。

## 返却内容

サイト、レポート／スキャン／ジャーニー ID、観察日時、関連するチェック、裏付けとなる URL、制限事項、および優先順位付けされた改善策。チェックの合格、ジャーニーの通過、および実際のビジネス成果を区別してください。
