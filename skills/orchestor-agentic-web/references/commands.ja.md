# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行や公開されたすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc agentic-web attestations get` | ドメインの署名付きスコアカードを取得する |
| `orc agentic-web check-feedback create` | 不正確なチェック結果を報告する |
| `orc agentic-web checks list` | Agentic Web チェックカタログを取得する |
| `orc agentic-web checks verify` | 選択した Agentic Web チェックを再実行する |
| `orc agentic-web directory explore` | ファセット別にディレクトリリソースをカウントする |
| `orc agentic-web directory search` | エージェント対応ディレクトリを検索する |
| `orc agentic-web discover` | インテントに基づいてエージェント対応サイトを検出する |
| `orc agentic-web journeys create` | エージェントジャーニーを開始する |
| `orc agentic-web journeys get` | エージェントジャーニーを取得する |
| `orc agentic-web journeys intents list` | キュレーションされたジャーニーインテントを一覧表示する |
| `orc agentic-web jwks get` | アテステーション検証キーを取得する |
| `orc agentic-web public sites get` | オーナーが公開したスコアカードを取得する |
| `orc agentic-web reports get` | Agentic Web レポートを取得する |
| `orc agentic-web scans create` | Agentic Web スキャンを開始する |
| `orc agentic-web scans get` | Agentic Web スキャンを取得する |
| `orc agentic-web sites feedback create` | サイトのエージェントフィードバックを送信する |
| `orc agentic-web sites feedback list` | サイトのエージェントフィードバックを一覧表示する |
| `orc agentic-web sites publication set` | サイトのスコアカードを公開または取り下げる |
| `orc agentic-web sites report get` | ドメインの最新の Agentic Web レポートを取得する |
| `orc agentic-web sites reports list` | ドメインの Agentic Web レポートを一覧表示する |
| `orc analytics crawlability get` | AI クローラーの robots.txt アクセスポリシーを取得する |
