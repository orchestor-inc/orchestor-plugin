# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc agentic-web attestations get` | Get a signed scorecard for a domain |
| `orc agentic-web check-feedback create` | Report an inaccurate check result |
| `orc agentic-web checks list` | Get the agentic web check catalog |
| `orc agentic-web checks verify` | Rerun selected agentic web checks |
| `orc agentic-web directory explore` | Count directory resources by facet |
| `orc agentic-web directory search` | Search the agent-ready directory |
| `orc agentic-web discover` | Discover agent-ready sites by intent |
| `orc agentic-web journeys create` | Start an agent journey |
| `orc agentic-web journeys get` | Get an agent journey |
| `orc agentic-web journeys intents list` | List curated journey intents |
| `orc agentic-web jwks get` | Get attestation verification keys |
| `orc agentic-web public sites get` | Get an owner-published scorecard |
| `orc agentic-web reports get` | Get an agentic web report |
| `orc agentic-web scans create` | Start an agentic web scan |
| `orc agentic-web scans get` | Get an agentic web scan |
| `orc agentic-web sites feedback create` | Submit agent feedback for a site |
| `orc agentic-web sites feedback list` | List agent feedback for a site |
| `orc agentic-web sites publication set` | Publish or withdraw a site's scorecard |
| `orc agentic-web sites report get` | Get the latest agentic web report for a domain |
| `orc agentic-web sites reports list` | List agentic web reports for a domain |
| `orc analytics crawlability get` | Get AI crawler robots.txt access policy |
