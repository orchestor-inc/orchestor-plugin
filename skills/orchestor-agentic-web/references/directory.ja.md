# ディスカバリー、ディレクトリ、および公開

ディスカバリー／検索／探索は、関連するサイトや既存のエビデンスを特定するのに役立ちます。返されたソースとクエリのスコープを保持してください。ディレクトリへの掲載は、品質、所有権、または現在の利用可能性を証明するものではありません。

読み取り専用の検査は、`sites publication set`、フィードバック作成、その他の書き込み処理とは分離されています。スキャンリクエストの一環としてサイトを公開しないでください。明示的な公開設定の変更を行う前に、現在の状態とユーザーが意図する可視性を検査し、その後に新しい状態を再読み取りしてください。
