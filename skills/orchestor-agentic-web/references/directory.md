# Discovery, directory, and publication

Discovery/search/explore help locate relevant sites and existing evidence. Keep
the returned source and query scope. A directory listing does not prove quality,
ownership, or current availability.

Read-only inspection is separate from `sites publication set`, feedback creation,
and other writes. Do not make a site public as part of a scan request. Before an
explicit publication change, inspect current state and the user's intended
visibility, then read back the new state.
