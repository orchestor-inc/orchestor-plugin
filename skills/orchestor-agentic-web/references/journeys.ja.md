# エージェントジャーニー

タスクに一致する場合は `agentic-web journeys intents list` からキュレーションされたインテントを選択するか、ユーザーの範囲が限定されたカスタムタスクを指定します。最初にモードコントラクトをお読みください。Browser モードでは公開情報の読み取りや UI 作業を評価できますが、Web モードではカスタムタスクが保守的に部分成功／失敗（partial/failure）に制限されます。モードごとの結果を同等のものとして比較しないでください。

**誤り:** ユーザーが公開サイトの監査を要求しているにもかかわらず、テストジャーニーに購入を依頼したり、アカウント変更を送信させたり、メッセージを送信させたりすること。

**正しい対応:** 読み取り専用の公開ナビゲーションタスクを使用し、期待されるエビデンスを特定して、実際に到達した結果を報告します。隔離された公開ブラウザから認証済み機能を推測してはなりません。外部への影響を伴うタスクについては、明示的な認可境界に従ってください。
