# スキャンリクエストと保存されたレポート

スキャン作成 URL は公開 HTTP(S) ドメインルートです。ベアドメインは受け入れられますが、パス、クエリ、フラグメント、および認証情報は拒否されます。個別の MCP URL は明示的な公開エンドポイントである必要があり、同様に認証情報、クエリ文字列、またはフラグメントを含めることはできません。エンドポイント URL にトークンを含めないでください。

**誤り:** レポートを読み取るたびに強制スキャンを要求することや、MCP サーバーが指定されていないにもかかわらず、スキャンによってそれが検出およびテストされたと主張すること。

**正しい対応:** 利用可能なレポートとその経過時間を検査します。タスクに応じて cache/freshness フィールドを設定してください。`force` は新規スキャンを開始するものであり、単なる表示の更新ではありません。browser オプションは、隔離された公開ブラウザを使用して、レンダリングされた DOM／アクセシビリティおよび WebMCP のエビデンスチェックを追加しますが、ユーザーのサインイン済みタブへのアクセスではありません。

スキャン／レポート ID を保持し、返されたリソースを検査してください。収集が受け入れられた状態（Accepted collection）は、完了したレポートではありません。サポートされていないターゲットやブロックされたターゲットは正確に報告してください。
