# ブランドとドメインの操作

アイデンティティを変更する前に、ワークスペースを解決し、既存のレコードを読み取ります。ブランド名、追跡対象ドメイン、引用ドメイン、および競合他社 ID は異なるオブジェクトです。

1. `orc brands list --help` を検査し、ワークスペースのブランドを一覧表示します。
2. 確認済みの名称およびウェブサイトから対象の ID を解決します。無関係なフィールドを保持し、更新前にリーフコマンドのスキーマを読み取ります。
3. 生成されたサジェストは未検証の候補として扱います。要求された変更のみを受け入れ、結果のレコードを再読み取りします。
4. ドメインの検証は個別に検査します。ドメインレコードが存在するだけでは、所有権、測定対象の網羅性、または回答が存在することは証明されません。

解決された ID、確認済みのファクト、変更点、および未解決のアイデンティティに関する疑問点を返します。親ワークフローはブランド ID をプロンプト、レポート、またはパーセプションに渡すことができます。ブランド解決の副作用として測定を開始しないでください。
