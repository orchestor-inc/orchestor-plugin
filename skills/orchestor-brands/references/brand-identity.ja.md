# ブランドおよび競合他社のアイデンティティ

ブランドを追加または更新する前に、既存のブランドを読み取ります。対象のブランドを ID および確認済みのウェブサイト / 名称で一致させます。表記の揺れを解決するために重複を作成しないでください。ワークスペースには複数のブランドや競合他社が含まれる場合があります。

要求された変更には brands、suggestions、および domains コマンドファミリーを使用します。サジェストは候補であり、検証済みの事実ではありません。指定されたサジェストのみを承認または拒否し、結果のレコードを再読み取りします。

更新をマージする前に、フィールドの挙動を検査します。省略された配列はその値を保持する場合がありますが、指定された配列は値を置き換える場合があります。無関係なエイリアス、競合他社、またはメタデータを保持してください。ドメイン所有権の検証は別の操作です。保存されたドメインレコード単体では、所有権やデータ収集を証明するものではありません。
