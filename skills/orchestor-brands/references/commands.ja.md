# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名称は公開 CLI レジストリに対して解決されました。これはルーティングの網羅性を証明するものであり、認証済みでの実行やすべての公開バイナリでの利用可能性を保証するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc brands create` | AI Search ブランドを作成 |
| `orc brands delete` | AI Search ブランドを論理削除 |
| `orc brands get` | AI Search ブランドを取得 |
| `orc brands list` | AI Search ブランドを一覧表示 |
| `orc brands suggestions list` | ブランドサジェストを一覧表示 |
| `orc brands update` | AI Search ブランドを更新 |
| `orc brands suggestions accept` | ブランドサジェストを承認 |
| `orc brands suggestions refresh` | ブランドサジェストを生成 |
| `orc brands suggestions reject` | ブランドサジェストを拒否 |
| `orc brands suggestions generations get` | ブランドサジェスト生成を取得 |
| `orc domains create` | 追跡対象ドメインを登録 |
| `orc domains delete` | 追跡対象ドメインを論理削除 |
| `orc domains get` | 追跡対象ドメインを取得 |
| `orc domains list` | 追跡対象ドメインを一覧表示 |
| `orc domains update` | 追跡対象ドメインを更新 |
| `orc domains verification get` | ドメイン検証ステータスを取得 |
| `orc domains verification refresh` | ドメイン検証を再確認 |
| `orc domains verify` | ドメインの DNS 検証をトリガー |
