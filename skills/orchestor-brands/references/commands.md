# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc brands create` | Create AI Search brand |
| `orc brands delete` | Soft-delete AI Search brand |
| `orc brands get` | Get AI Search brand |
| `orc brands list` | List AI Search brands |
| `orc brands suggestions list` | List brand suggestions |
| `orc brands update` | Update AI Search brand |
| `orc brands suggestions accept` | Accept a brand suggestion |
| `orc brands suggestions refresh` | Generate brand suggestions |
| `orc brands suggestions reject` | Reject a brand suggestion |
| `orc brands suggestions generations get` | Get brand suggestion generation |
| `orc domains create` | Register a tracked domain |
| `orc domains delete` | Soft-delete a tracked domain |
| `orc domains get` | Get a tracked domain |
| `orc domains list` | List tracked domains |
| `orc domains update` | Update a tracked domain |
| `orc domains verification get` | Get domain verification status |
| `orc domains verification refresh` | Recheck domain verification |
| `orc domains verify` | Trigger DNS verification for a domain |
