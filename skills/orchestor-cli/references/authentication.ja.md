# 認証とワークスペースの選択

CLI と MCP の認証情報は別個のものです。CLI の状態には `orc status` および `orc auth status` を
使用します。ホストされた MCP 接続には、クライアントの MCP ステータス / OAuth フローを使用します。
スキルをインストールするための GitHub 権限は、製品へのアクセス権を付与するものではありません。

**誤り:** トークンファイルを読み取ったり、その値を出力したり、ワークスペースリンクが
設定済みのサービスエンドポイントと異なって見えるという理由で API の URL を変更したりすること。

**正しい対応:** 接続状態と選択されたワークスペースを報告します。サポートされている
ログインフローに従います。エンドポイントまたはワークスペースがリクエストと競合する場合は、
書き込みを行う前にその競合を解決します。アクセストークンをチャットに貼り付けてはなりません。

`orc workspace list` はワークスペースの一覧表示コマンドではありません。アクセス可能な
ワークスペースを見つけるには `orc workspaces list --help` を検査してください。`orc workspace`
にはローカルでの選択 / リンク用のヘルパーが含まれています。リモートワークスペースの変更と、
ローカルで選択されたワークスペースの変更を区別してください。

無人アクセスには、要求された API キーまたはサービスアカウントのフローのみを使用します。
人間のセッショントークンをコピーするのではなく、コマンドでサポートされているスコープと有効期限を検査してください。
返されたシークレットは、ユーザーが承認したシークレット保存先に格納します。
その保存先が指定されていない場合は、シークレット以外のリクエスト詳細を準備し、
認証情報を作成する前に保存場所を解決してください。
