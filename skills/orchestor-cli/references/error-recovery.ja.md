# エラー復旧

| 事象 | 対処 |
| --- | --- |
| リーフコマンドの欠落または不明なフラグ | インストールされているバージョンと正確なリーフヘルプを確認する。ドキュメントに記載されたアップグレードガイダンスを使用する |
| 認証の失敗 | 接続状態を調査する。サポートされているログインを使用する。盲目的に再試行しない |
| 権限の失敗 | ワークスペースと必要なロールを確認する。オペレーター資格情報で代用しない |
| バリデーションの失敗 | スキーマを参照して示された入力を修正する。デフォルト値を勝手に創作しない |
| レート制限 | Retry-After を遵守し、再試行回数を制限する |
| 非同期タイムアウト | 返されたジョブ ID を保持し、そのジョブを調査する |
| 書き込み結果の曖昧さ | 返された ID で読み取るか、同一の冪等なリクエストを再試行する |
| 空の結果 | データが存在しないと結論付ける前に、フィルター、期間、ページネーション、およびデータの可用性を確認する |

簡潔なエラーと、サポートされている次の手順を返してください。問題の診断のために、ヘッダー、トークン、
生の資格情報設定、または無関係な顧客データを出力（エコー）しないでください。
