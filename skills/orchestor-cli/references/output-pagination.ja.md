# 出力とページネーション

構造化された作業には `--format json` を優先してください。必要なフィールドのみを
保持するには `--fields` を使用し、単一のパスには `--field` を使用します。すべてのレスポンスが最上位の
配列であると想定しないでください。パースする前にそのエンベロープを調査してください。成果物が
必要な場合にのみ、明示的な出力先を指定して `--output` を使用してください。公開リポジトリ内に
顧客のエクスポートデータを保存しないでください。

**誤り:** 最初のページを完全なデータセットとして扱う、あるプロバイダーのカーソルを
別のエンドポイントで再利用する、またはフィルタリングする前にすべての結果をリクエストする。

**正しい方法:** 最初にフィルタリングし、上限が設定されたページを読み取り、エンドポイントの実際の
継続コントラクトに従う。一般的なページネーション対応コマンドは `--page-all` をサポートし、
NDJSON を出力する場合があります。リサーチプロバイダーは代わりに完全な `next_request`
オブジェクトを返すことがあります。これは変更せずにそのまま返し、初期フィルターとマージしないでください。

継続トークンを伴う空のデータページは完了を意味しません。継続中もフィルター、
ロケール、ソート順、およびページ制限を維持してください。タスクの制限値で
停止した場合は、部分的なカバレッジを報告してください。欠落しているデータはゼロではなく、不明として扱ってください。
