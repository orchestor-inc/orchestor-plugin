# 自動化アクセス

明示的に要求された自動化アイデンティティの変更には、サポートされている API キーまたは
サービスアカウントのコマンドを使用してください。スコープ、有効期限、現在のキー、および対象の
ワークスペースを調査します。資格情報のプロビジョニングは、単純なステータスチェックの一部ではありません。

SKILL.md、プラグインマニフェスト、コマンド履歴、公開 issue、またはチャットに資格情報の値を決して配置しないでください。
承認されたシークレットの保存先を使用してください。シークレット値ではなく、不透明なキー
またはアカウント ID と付与されたスコープを報告してください。

アクセスの作成または変更後は、承認された操作のみを検証してください。他のテナントを
探索したり、ワークスペースでの成功から組織全体のアクセス権を推測したりしないでください。
