# ブラウザコンテキストとセッション

公開されている browser-context および browser-session コマンドファミリーは、製品リソースを
公開するものです。これらは内部のオペレーターブラウザブリッジではなく、ユーザーのデスクトップセッションを
制御する権限でもありません。

コンテキストの作成、非アクティブ化、または削除を行う前に、現在のレコードと正確なコマンドヘルプを
確認してください。これらは明確に異なるライフサイクル操作です。無関係なコンテキストはそのまま保持し、
アクセスを診断するために資格情報やプロファイルストレージを調査しないでください。

リストに表示されたセッションは、ページが読み込まれたことやユーザータスクが成功したことの証明にはなりません。
返された状態と証拠のみを報告してください。必要なブラウザ操作が公開サーフェスに存在しない場合は、
内部ホストツールに頼るのではなく、その制限事項を述べてください。
