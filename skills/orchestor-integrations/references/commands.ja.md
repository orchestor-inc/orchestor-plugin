# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証済みでの実行や、公開されているすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされている末端コマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc browser-context create` | ワークスペースブラウザコンテキストを作成する |
| `orc browser-context deactivate` | アカウントの無効化を記録する |
| `orc browser-context delete` | ワークスペースブラウザコンテキストを削除する |
| `orc browser-context list` | ワークスペースブラウザコンテキストを一覧表示する |
| `orc browser-session list` | ワークスペースブラウザセッションを一覧表示する |
| `orc connect-sessions create` | コネクター認証セッションを作成する |
| `orc connections bot-history-import` | 保持されている Vercel bot 履歴を 1 回インポートする |
| `orc connections get` | コネクター接続を取得する |
| `orc connections list` | コネクター接続を一覧表示する |
| `orc connections properties-create` | GA4 プロパティを作成する |
| `orc connections properties-list` | アクセス可能なアナリティクスプロパティを一覧表示する |
| `orc connections referral-report-get` | Google Analytics のリファラーデータを取得する |
| `orc connections update` | コネクターデータソースを選択する |
| `orc connections web-streams-create` | GA4 ウェブデータストリームを作成する |
| `orc connections web-streams-list` | GA4 ウェブデータストリームを一覧表示する |
