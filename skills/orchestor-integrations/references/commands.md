# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc browser-context create` | Create a workspace browser context |
| `orc browser-context deactivate` | Record account deactivation |
| `orc browser-context delete` | Delete a workspace browser context |
| `orc browser-context list` | List workspace browser contexts |
| `orc browser-session list` | List workspace browser sessions |
| `orc connect-sessions create` | Create a connector authorization session |
| `orc connections bot-history-import` | Import retained Vercel bot history once |
| `orc connections get` | Get a connector connection |
| `orc connections list` | List connector connections |
| `orc connections properties-create` | Create a GA4 property |
| `orc connections properties-list` | List accessible analytics properties |
| `orc connections referral-report-get` | Get Google Analytics referral data |
| `orc connections update` | Select a connector data source |
| `orc connections web-streams-create` | Create a GA4 web data stream |
| `orc connections web-streams-list` | List GA4 web data streams |
