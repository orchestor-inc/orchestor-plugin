# MCP クライアント

クライアントのドキュメントに記載されている HTTP トランスポートと OAuth サポートを使用して、https://mcp.orchestor.io/mcp を利用してください。Claude Code、Codex、および Cursor は異なる設定インターフェースを使用します。JSON のサーバーマップを TOML 専用の場所に貼り付けたり、設定ファイル全体を置き換えたりしないでください。

**誤り:** URL を追加した後に「接続済み」と報告すること、または Orchestor を追加するためにすべての MCP サーバーを上書きすること。

**正しい対応:** 他のエントリを保持し、OAuth で認証し、接続されたツール一覧を確認して、認可済みの小規模な読み取りを実行すること。MCP のツール名およびスキーマは CLI コマンドと同一ではありません。名前空間を推測したツール名へと機械的に変換するのではなく、実際のツール宣言を検査してください。

CLI ログインは MCP OAuth とは別個のものです。スキルのインストールはいずれも付与しません。クライアントがサーバーを読み込めない場合は、実際のエラーと関連するセットアップ手順を報告してください。オペレーターの認証情報を使用してワークスペースの認可をバイパスしないでください。
