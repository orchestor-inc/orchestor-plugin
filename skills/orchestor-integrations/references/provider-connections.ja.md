# プロバイダー接続

新しい接続セッションを開始する前に、現在の接続を確認してください。現在の接続セッションプロバイダーのセットには、Google Analytics、Google Search Console、Google Ads、Cloudflare、Amazon CloudFront、および Vercel が含まれます。プロバイダーやスコープを約束する前に、インストールされているヘルプを確認してください。

Google Analytics の access_mode はデフォルトで read_only です。manage はプロパティ／ウェブストリーム作成のために、より広範な analytics.edit アクセスを要求します。管理アクセスは、要求された管理タスクにのみ使用してください。プロパティの作成、ストリームの作成、およびリファラーレポートの読み取りは別々の操作です。

**誤り:** データが見つからないたびにより広範なスコープで再接続すること、または OAuth の完了が過去のイベントがインポートされたことを意味すると推測すること。

**正しい対応:** 選択されたソース／プロパティ、接続状態、権限、および収集期間を検証すること。要求された履歴のインポートについては、返されたジョブまたはレシートを個別に検査してください。不足しているデータや権限の制限を正確に返してください。
