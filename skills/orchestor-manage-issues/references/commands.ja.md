# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証済みでの実行や、公開されているすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされている末端コマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc issues activity list` | Issue のアクティビティを一覧表示する |
| `orc issues batch update` | Issue 操作を一括処理する |
| `orc issues comments create` | Issue にコメントする |
| `orc issues comments list` | Issue のコメントを一覧表示する |
| `orc issues create` | Issue を作成する |
| `orc issues delete` | Issue を論理削除する |
| `orc issues favorites disable` | Issue のお気に入りを解除する |
| `orc issues favorites enable` | Issue をお気に入りに追加する |
| `orc issues get` | Issue を取得する |
| `orc issues list` | Issue を一覧表示する |
| `orc issues preferences get` | 個人の Issue 設定を取得する |
| `orc issues preferences update` | 個人の Issue 設定を保存する |
| `orc issues reactions create` | Issue にリアクションする |
| `orc issues reactions delete` | Issue のリアクションを削除する |
| `orc issues reactions list` | Issue のリアクションを一覧表示する |
| `orc issues relations create` | Issue のリレーションを作成する |
| `orc issues relations delete` | Issue のリレーションを削除する |
| `orc issues relations list` | Issue のリレーションを一覧表示する |
| `orc issues restore` | Issue を復元する |
| `orc issues subscriptions disable` | Issue の購読を解除する |
| `orc issues subscriptions enable` | Issue を購読する |
| `orc issues update` | Issue を更新する |
| `orc issues views create` | IssueView を作成する |
| `orc issues views defaults disable` | IssueView のデフォルト設定をクリアする |
| `orc issues views defaults enable` | IssueView のデフォルトを設定する |
| `orc issues views delete` | IssueView を削除する |
| `orc issues views get` | IssueView を取得する |
| `orc issues views list` | 表示可能な IssueView を一覧表示する |
| `orc issues views update` | IssueView を更新する |
