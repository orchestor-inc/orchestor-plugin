# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc issues activity list` | List Issue activity |
| `orc issues batch update` | Batch Issue operations |
| `orc issues comments create` | Comment on an Issue |
| `orc issues comments list` | List Issue comments |
| `orc issues create` | Create an Issue |
| `orc issues delete` | Soft-delete an Issue |
| `orc issues favorites disable` | Unfavorite an Issue |
| `orc issues favorites enable` | Favorite an Issue |
| `orc issues get` | Get an Issue |
| `orc issues list` | List Issues |
| `orc issues preferences get` | Get personal Issue preferences |
| `orc issues preferences update` | Save personal Issue preferences |
| `orc issues reactions create` | React to an Issue |
| `orc issues reactions delete` | Remove an Issue reaction |
| `orc issues reactions list` | List Issue reactions |
| `orc issues relations create` | Create an Issue relation |
| `orc issues relations delete` | Delete an Issue relation |
| `orc issues relations list` | List Issue relations |
| `orc issues restore` | Restore an Issue |
| `orc issues subscriptions disable` | Unsubscribe from an Issue |
| `orc issues subscriptions enable` | Subscribe to an Issue |
| `orc issues update` | Update an Issue |
| `orc issues views create` | Create an IssueView |
| `orc issues views defaults disable` | Clear an IssueView default |
| `orc issues views defaults enable` | Set an IssueView default |
| `orc issues views delete` | Delete an IssueView |
| `orc issues views get` | Get an IssueView |
| `orc issues views list` | List visible IssueViews |
| `orc issues views update` | Update an IssueView |
