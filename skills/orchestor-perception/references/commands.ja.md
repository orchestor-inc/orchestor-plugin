# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03 、 CLI ソースバージョン 0.6.2 。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行やすべての公開バイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を参照してください。

| コマンド | 目的 |
| --- | --- |
| `orc perception observations import` | 引用されたブランド属性の観測結果をインポートする |
| `orc perception text list` | 境界付きの Perception テキスト証拠を読み取る |
| `orc perception-attributes create` | カスタムの Perception 属性を作成する |
| `orc perception-attributes delete` | Perception 属性を非表示にする |
| `orc perception-attributes list` | 管理対象の Perception 属性を一覧表示する |
| `orc perception-attributes update` | Perception 属性の名前を変更する |
| `orc reports perception get` | Perception レポート |
| `orc reports perception sources list` | Perception 属性のソース証拠を一覧表示する |
| `orc reports perception-rankings get` | Perception 属性ランキングレポート |
