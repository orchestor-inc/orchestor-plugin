# インポートのセマンティクス

`orc perception observations import --help` を参照してください。本文には answer_id 、 answer_digest 、 analysis_label 、および observations が必要です。各観測結果には、ワークスペースの brand_id 、 attribute 、 start 、 end 、および quote が必要です。現在の長さと件数の制約に従ってください。不足している証拠を推測したテキストで埋めないでください。

インポートには、関連するワークスペースの権限が必要です。これらはリクエスト内に存在するブランドの属性観測結果のみを置き換え、他のブランドおよび元の回答を保持します。したがって、含まれる 1 つのブランドの部分的なセットが、そのブランドの既存のアノテーションを置き換える可能性があります。送信前に意図したスコープを検査してください。

**誤り:** 都合の良い引用を 1 件インポートし、単に行が追加されるだけだと想定すること。

**正しい方法:** 置換スコープを明示し、影響を受けるブランドに対して意図した完全なセットを含めること。再試行用の安定したべき等性を備えた UTF-8 JSON ファイルで `--stdin` を使用し、レシートを確認してください。ダイジェストの競合はソースが変更されたことを意味します。権限エラーがあっても、オペレーター認証情報の使用は正当化されません。
