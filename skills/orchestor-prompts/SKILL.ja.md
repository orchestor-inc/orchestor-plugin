# プロンプトとそのコンテキストの操作

質問セットをその実行から分離します。顧客、製品、意思決定ステージ、市場、および関連する競合他社といった、ユーザーのビジネスコンテキストを再利用してください。ラベル付けをせずに任意のプロンプトボリュームを作成したり、ブランド名を含む結果と含まない結果を混在させたりしないでください。

1. 現在のプロンプト / トピック / ペルソナの ID と対象のワークスペースを読み取ります。
2. リクエストされた質問とコンテキストのみを下書きまたは編集します。 `orc prompts create --help` またはリクエストされたリーフのヘルプを使用して正確なフィールドを確認します。
3. 生成された提案を採用する前に確認します。ユーザーの編集内容を保持してください。
4. 下書きの作成、定期的なモニタリングの有効化、無効化、および削除を明確に区別します。下書きのリクエストは、有効化や有料実行を承認するものではありません。
5. 変更されたリソースを読み戻し、 ID 、状態、およびコンテキストを返します。

収集がリクエストされた場合にのみ、実行可能な既存のプロンプト ID を `orchestor-runs` に渡します。現在の規約では、無効化されたプロンプトであっても手動で実行可能な場合があります。無効化を削除と同等とみなすのではなく、状態を検査してください。
