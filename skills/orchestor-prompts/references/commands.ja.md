# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03 、 CLI ソースバージョン 0.6.2 。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行やすべての公開バイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を参照してください。

| コマンド | 目的 |
| --- | --- |
| `orc personas create` | ペルソナを作成する |
| `orc personas delete` | ペルソナを論理削除する |
| `orc personas get` | ペルソナを取得する |
| `orc personas list` | ペルソナを一覧表示する |
| `orc personas update` | ペルソナを更新する |
| `orc personas suggestions refresh` | ペルソナの提案を生成する |
| `orc personas suggestions generations get` | ペルソナ提案の生成を取得する |
| `orc prompts create` | AI Search プロンプトを作成する |
| `orc prompts delete` | アクティブなビューから AI Search プロンプトを削除する |
| `orc prompts disable` | AI Search プロンプトを無効化する |
| `orc prompts enable` | AI Search プロンプトを有効化する |
| `orc prompts get` | AI Search プロンプトを取得する |
| `orc prompts list` | AI Search プロンプトを一覧表示する |
| `orc prompts suggestions list` | プロンプトの提案を一覧表示する |
| `orc prompts tags get` | プロンプトのタグを一覧表示する |
| `orc prompts tags update` | プロンプトのタグを置換する（一括） |
| `orc prompts update` | AI Search プロンプトを更新する |
| `orc prompts suggestions accept` | 提案を採用する（プロンプトに昇格） |
| `orc prompts suggestions refresh` | プロンプトの提案を生成する |
| `orc prompts suggestions reject` | 提案を却下する |
| `orc prompts suggestions generations get` | プロンプト提案の生成を取得する |
| `orc tags create` | タグを作成する |
| `orc tags delete` | タグを論理削除する |
| `orc tags list` | タグを一覧表示する |
| `orc tags update` | タグを更新する |
| `orc topics create` | AI Search トピックを作成する |
| `orc topics delete` | AI Search トピックを論理削除する |
| `orc topics get` | AI Search トピックを取得する |
| `orc topics list` | AI Search トピックを一覧表示する |
| `orc topics suggestions list` | トピックの提案を一覧表示する |
| `orc topics update` | AI Search トピックを更新する |
| `orc topics suggestions accept` | トピックの提案を採用する（トピックに昇格） |
| `orc topics suggestions refresh` | トピックの提案を生成する |
| `orc topics suggestions reject` | トピックの提案を却下する |
| `orc topics suggestions generations get` | トピック提案の生成を取得する |
