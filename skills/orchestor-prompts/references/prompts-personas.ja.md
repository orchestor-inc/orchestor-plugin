# プロンプト、トピック、タグ、およびペルソナ

ワークスペース 内の既存の関連する質問を確認した後にのみ、プロンプト を作成してください。ブランド/トピック ID と要求された正確な文言を解決してください。特定の要求を大規模に合成されたプロンプトセットに変換しないでください。

トピックとタグは観測結果を整理するものであり、質問の意味を変更するものではありません。タグセットを更新する際は、既存のタグを検査し、ユーザーがセット全体の置換を要求した場合を除き、無関係なタグを保持してください。提案は承認前にレビューが必要です。

ペルソナは保存されたレコードまたは実行コンテキストにすることができます。現在設定されているからといって、過去の回答でペルソナが使用されたと見なさないでください。観測結果によって返された実際のペルソナまたは実行アイデンティティを記録してください。

**誤り:** ドラフトを作成して直ちに実行すること、または「この質問を追加して」がモニタリング要求のように聞こえたという理由でモニタリングを有効化すること。

**正しい対応:** ドラフト ID と状態を返します。未解決の必要なアクティベーション決定についてのみ質問してください。明示的な実行には、有効な保存済みプロンプト状態とサポートされているチャネルを使用してください。現在の設定に対する変更によって過去のエビデンスが書き換えられることはありません。
