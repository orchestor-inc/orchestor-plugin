# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行や公開されたすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を参照してください。

| コマンド | 目的 |
| --- | --- |
| `orc report` | Workspace の visibility、sentiment、および citations を要約 |
| `orc reports bots get` | ボット / AI クローラーのトラフィックレポート |
| `orc reports citations get` | Citations レポート |
| `orc reports query-fanouts get` | Query fanouts レポート |
| `orc reports referrals get` | AI アシスタントのリファラートラフィックレポート |
| `orc reports sentiment get` | Sentiment レポート |
| `orc reports visibility get` | Visibility レポート |
| `orc reports web-search-results get` | Web 検索結果レポート |
| `orc websites visit-logs-list` | 観測された Web サイトへのボット訪問を一覧表示 |
