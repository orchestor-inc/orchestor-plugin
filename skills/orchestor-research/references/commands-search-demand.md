# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc research google-keywords categories list` | List keyword research categories |
| `orc research google-keywords for-categories list` | Discover keywords within categories |
| `orc research google-keywords for-site list` | Discover keywords relevant to a website |
| `orc research google-keywords history get` | Get historical keyword metrics |
| `orc research google-keywords ideas list` | Discover keyword ideas from seed terms |
| `orc research google-keywords intent get` | Classify keyword search intent |
| `orc research google-keywords intersection list` | Find shared or missing domain keywords |
| `orc research google-keywords locales list` | List keyword research locations and languages |
| `orc research google-keywords map` | Discover keyword research primitives |
| `orc research google-keywords overview get` | Compare keyword metrics, difficulty and intent |
| `orc research google-keywords ranked list` | Find keywords where a domain ranks |
| `orc research google-keywords related list` | Find related keywords |
| `orc research google-keywords serp get` | Inspect Google results for a keyword |
| `orc research google-keywords suggestions list` | Find keywords containing a seed phrase |
| `orc research google-keywords volume get` | Get Google keyword search volume |
| `orc research google-trends get` | Compare Google Trends interest and discover rising queries |
