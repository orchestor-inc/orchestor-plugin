# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行や公開されたすべてのバイナリでの利用可能性を保証するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc research web crawl` | サイトページを巡回して取得する |
| `orc research web extract` | ページからセレクターまたは JSON-LD を抽出する |
| `orc research web history get` | 公開ページのキャプチャ履歴を読み取る |
| `orc research web index get` | 保存された公開 URL インベントリを読み取る |
| `orc research web map` | サイトの URL を検出する |
| `orc research web scrape` | 1 つ以上のページを取得する |
| `orc research web sites create` | 空の Web サイトインデックスを登録する |
| `orc research web sites discover` | Web サイトのホームページからリンクされている関連サイトを検索する |
| `orc research web sites list` | 登録されている Web サイトを一覧表示する |
