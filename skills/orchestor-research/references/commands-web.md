# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc research web crawl` | Traverse and retrieve site pages |
| `orc research web extract` | Extract selectors or JSON-LD from pages |
| `orc research web history get` | Read public page capture history |
| `orc research web index get` | Read the saved public URL inventory |
| `orc research web map` | Discover site URLs |
| `orc research web scrape` | Retrieve one or more pages |
| `orc research web sites create` | Register an empty website index |
| `orc research web sites discover` | Find related sites linked from a website homepage |
| `orc research web sites list` | List registered websites |
