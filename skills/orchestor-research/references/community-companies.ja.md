# コミュニティ、プレスリリース、およびスタートアップ調査

エビデンスに一致するソースファミリーを選択してください:

- 開発者記事、トピック、ユーザー、およびコミュニティ活動には Qiita と Zenn。
- 記事、クリエイター、タグ、興味・関心、およびトレンドには note。
- 企業のアナウンス、リリース、カテゴリ、および公開日には PR TIMES。
- 掲載企業、創業者、ローンチ、または投稿には YC および a16z speedrun。

ソース固有のリストや検索には、それぞれ異なるフィルタリングとページネーションがあります。詳細を取得する前に、実際のソース ID を解決してください。創業者の名前が一致するからといってその企業がプログラムに採択されていると想定したり、プレスリリースを客観的な独立した報道として扱ったりしないでください。

**誤り:** リリース日と取得日を 1 つのタイムラインとして結合したり、部分的なリストを市場全体と呼んだりすること。

**正解:** イベント/公開のタイムスタンプを取得時刻とは別に保持し、どのソースおよびページを検索したかを明記し、停止境界を報告すること。ローンチ投稿、ディレクトリのエントリ、および法的な企業記録では、裏付けられる主張が異なります。
