# 日本の SaaS 調査ソース

| ソース | 有用な開始ポイント |
| --- | --- |
| BOXIL | カテゴリ、製品、ランキング、製品詳細、レビュー、検索 |
| ITreview | 製品詳細、レビュー、代替品、比較、カテゴリ、市場グラフ |
| ITトレンド | カテゴリディレクトリ、製品、ランキング、課題、市場 |
| ASPIC | カテゴリ、サービス、記事、著者、検索 |

検出後は、そのソース自体の製品/ベンダー/カテゴリ識別子を使用してください。あるサービスの ID を別のプロバイダーに渡したり、同名の製品が同じエディション、特定国向けの提供内容、または同一ベンダーであると想定したりしないでください。

**誤り:** ベンダーのマーケティング文句を独自に検証された機能と呼んだり、ソースとサンプルサイズを記録せずに総合評価を比較したりすること。

**正解:** ベンダーの記述、レビュアーのレポート、および独自の統合考察を分離すること。利用可能な場合はソースの URL/ID、取得日、およびバージョン/プランを記録すること。レビューエンドポイントがエビデンスを返さない場合は、レビューやゼロ評価を捏造しないでください。

代替品やランキングについては、そのソースがカテゴリと順序付けをどのように定義しているかを記録してください。ソースのランキングは、市場全体の客観的な品質ランキングではありません。リクエストされた比較に必要な製品詳細/レビューのスライスのみを読み込んでください。

[正確なコマンドカタログ](commands-saas.ja.md)。
