# ソーシャル、広告、動画、および文字起こしのエビデンス

サポートされているコマンドファミリーには、LinkedIn、X、Reddit、YouTube、TikTok、および Meta Ads が含まれます。それぞれの機能は異なります。すべてが同様に検索、コメント、文字起こし、または分析をサポートしていると想定せず、正確なリーフを検査してください。

search/list を使用して ID を検出し、選択した投稿、プロフィール、動画、またはコメントを取得します。プロフィール URL、数値の会社 ID、アカウントハンドル、および投稿 ID には互換性がありません。LinkedIn の現在の会社（current-company）フィルターには、会社名や URL ではなく数値の会社 ID が必要です。人物検索には引き続きクエリが必要です。

**誤り:** 「念のため」返されたすべての LinkedIn 行をエンリッチしたり、曖昧な名前の一致から個人を特定したり、文字起こしなしで動画の要約を提示したりすること。

**正解:** 行数を制限し、関連するレコードを選択し、必要な場合にのみオプションのプロフィールエンリッチメントを要求すること。現在の LinkedIn の include=profile オプションでは、返される行ごとに最大 4 つのプロバイダークレジットが追加される可能性があります。返された帰属情報を保持し、利用できない文字起こしやコメントは利用不可としてマークすること。

元の投稿とコメント/返信、広告とオーガニックな言及、プロバイダーの指標と因果関係の主張を区別してください。公開された投稿には個人データが含まれている場合があります。ユーザーのタスクに必要なもののみを返し、機微な個人属性や非公開の個人属性を推測しないでください。調査の一環としてのアウトリーチやメッセージ送信は含まれません。
