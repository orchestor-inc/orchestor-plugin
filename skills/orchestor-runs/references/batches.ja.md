# バッチ実行

バッチは、要求された境界付きセットに対してのみ使用してください。`runs batches create --help` を参照してください。
各リクエストには、バッチ内で一意の custom_id が必要です。異なるプロンプトやチャネルは個別のリクエストとなります。本文（body）を構成する前に、現在の最大サイズおよび completion-window の制約を確認してください。これらは上限であり、目標サイズではありません。

**誤り:** 承認なしに要求された 10 件のプロンプトを利用可能なすべてのチャネルに展開することや、不足している回答を得るために部分的に完了したバッチ全体を再試行すること。

**正しい対応:** 意図する プロンプト × チャネル のスコープを提示し、1 回送信して、その batch ID を保持します。項目ごとの結果と custom_id を追跡します。結果を収集し、返されたとおりに completed、failed、canceled、expired、および still-pending の各項目を個別に報告します。既存の結果を確認した上で、未解決の承認済み作業のみを再試行します。

延長された completion window は期限のリクエストであり、成功を保証するものではありません。期限切れ件数（expiry count）を完了した観測として扱わないでください。レコードの削除と実行のキャンセルは異なる操作です。要求された操作のみを使用してください。
