# 測定構成

ワークスペースの測定構成、ターゲット、およびリビジョンを変更する前に読み取ってください。言語、ロケーション、プラットフォーム選択、プロンプト状態、および観測履歴は別個の概念です。

現在の default-location コントラクトでは、地域／都市の実行ロケーションではなく、global、または 2 文字の大文字の国コードを持つ country をサポートしています。言語は ja-JP などの言語タグです。プラットフォーム選択には対象となるコンシューマーチャネルを使用する必要があり、直接の API チャネルを挿入してはなりません。

**誤り:** 要求された 1 つのフィールドと推測に基づく他の値で構成を上書きすることや、新しいデフォルトによって過去のレポートが変更されたと主張すること。

**正しい対応:** 現在の必要な形状（shape）を取得し、要求された値のみを変更して、サポートされている完全な更新を送信した上で、それを再度読み取ります。リビジョン ID が返された場合は保持します。新しい構成は、将来の収集とは分けて報告してください。
