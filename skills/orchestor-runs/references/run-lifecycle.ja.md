# Run ライフサイクル

新しい実行（run）には、保存済みの prompt_id と対象となる model_channel_id が必要です。`orc channels list` および `orc runs create --help` を確認してください。公開コントラクトでは、新しい測定に対して直接のベンダー API チャネルおよびレガシーなエイリアスが拒否されます。

**誤り:** 要求された ChatGPT UI の観測を直接の API 呼び出しに置き換えることや、最初の実行の待機がタイムアウトしたために 2 つ目の実行を作成すること。

**正しい対応:** 要求された観測チャネルを維持し、返された run ID を保存し、同一の実行を調べるために `runs get` / `runs results get` を使用します。サポートされている場合は、境界付きの `--wait`、`--timeout`、および `--poll-interval` を使用してください。

指定された brand_id または topic_id は、保存されたプロンプトと一致しなければならないアサーションである場合があり、プロンプトのターゲットを変更するものではありません。Persona、region、language、および country フィールドにはそれぞれ異なる意味があります。カタログ ID と自由形式のコンテキストが交換可能であると仮定するのではなく、フィールドコントラクトを確認してください。

transcript 要求フラグは、公開 messages フィールドや取得可能なトランスクリプトを保証するものではありません。実際に返された answer/result フィールドのみを報告してください。キャンセルのリクエストは、すでに完了した結果を消去したり、返金を証明したりするものではありません。
