# 商品および AI ショッピングエビデンスを分析する

ショッピングエビデンスを比較する前に、商品を解決（特定）してください。名前の一致だけでは、商品またはバリアントのアイデンティティを確立するのに十分ではありません。

## 適用するケース

「どの商品が表示されるか？」、「競合商品を比較する」、「ショッピング需要を調査する」、「マーチャントを分析する」、または明示的に要求された商品カタログの更新に使用します。

## 手順

1. ワークスペース、商品 ID または URL、市場、および期間を確認します。
2. 別のレコードを抽出または作成する前に、既存の商品レコードを確認します。
   マッチングには [商品アイデンティティ](references/product-identity.ja.md) を使用してください。
3. 質問に答えるレポートを選択します。[レポート選択](references/reports.ja.md) を使用してください。
4. 境界付きの結果を取得し、裏付けとなる商品／マーチャントのエビデンスを調査します。
5. 観測された表示（appearances）および順位を、推測された需要やコンバージョンと区別します。
6. 要求されたカタログ変更については、該当するフィールドのみを準備し、再度読み取って確認します。
   ページからの抽出によって生成されるのはエビデンス／候補であり、自動的に検証された事実ではありません。

## クイックスタート

```bash
orc products list --workspace WORKSPACE_ID --limit 20 --format json
orc products extract --help
orc reports shopping-performance get --help
```

## 返却内容

商品／バリアントおよびマーチャントのアイデンティティ、レポートタイプ、期間およびスコープ、返却されたメトリクスとエビデンス、および不足しているカバレッジ。返却されたデータで立証されていない場合、売上、収益、在庫、または価格の最新性を主張してはなりません。
