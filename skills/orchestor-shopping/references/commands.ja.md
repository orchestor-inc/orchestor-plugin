# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証された実行や公開されたすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、パーミッション、および制限については、インストールされているリーフコマンドの `--help` を参照してください。

| コマンド | 目的 |
| --- | --- |
| `orc products attributes list` | 商品属性を一覧表示する |
| `orc products competitors list` | 競合するショッピング結果を一覧表示する |
| `orc products create` | 商品を作成する |
| `orc products delete` | 商品を削除する |
| `orc products extract` | 公開されている商品 URL から商品ファクトを抽出する |
| `orc products fanouts list` | 商品ファンアウトを一覧表示する |
| `orc products get` | 商品を取得する |
| `orc products list` | 商品を一覧表示する |
| `orc products prompts list` | 商品プロンプトを一覧表示する |
| `orc products resolve-jan` | JAN をエビデンスに基づく商品アイデンティティおよび URL 候補に解決する |
| `orc products summary get` | 商品サマリーを取得する |
| `orc products update` | 商品を更新する |
| `orc products attribute-keys list` | 商品属性キーを一覧表示する |
| `orc reports merchants get` | マーチャントレポートを取得する |
| `orc reports shopping-demand get` | ショッピング需要レポートを取得する |
| `orc reports shopping-performance get` | ショッピングパフォーマンスレポートを取得する |
| `orc reports shopping-trend get` | ショッピングトレンドレポートを取得する |
