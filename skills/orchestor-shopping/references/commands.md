# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc products attributes list` | List product attributes |
| `orc products competitors list` | List competing shopping results |
| `orc products create` | Create products |
| `orc products delete` | Delete products |
| `orc products extract` | Extract product facts from public product URLs |
| `orc products fanouts list` | List product fanouts |
| `orc products get` | Get product |
| `orc products list` | List products |
| `orc products prompts list` | List product prompts |
| `orc products resolve-jan` | Resolve a JAN to evidenced product identities and URL candidates |
| `orc products summary get` | Get product summary |
| `orc products update` | Update products |
| `orc products attribute-keys list` | List product attribute keys |
| `orc reports merchants get` | Get merchants report |
| `orc reports shopping-demand get` | Get shopping demand report |
| `orc reports shopping-performance get` | Get shopping performance report |
| `orc reports shopping-trend get` | Get shopping trend report |
