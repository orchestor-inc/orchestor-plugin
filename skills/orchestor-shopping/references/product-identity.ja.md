# 比較前の製品アイデンティティ

アイテムを区別するには、 ID 、確認済み URL 、ブランド、およびサポートされている製品識別子を使用してください。製品ファミリー、特定のバリアント、バンドル、および小売業者のリスティングは、それぞれ異なるものを指す場合があります。これらを暗黙的に統合しないでください。

**誤り:** 一致する表示名や抽出された JAN 候補が、すべての市場で要求された製品を一意に識別すると想定すること。

**正しい対応:** 返された識別子とソースエビデンスを検査し、曖昧さを保持してください。 `products resolve-jan` は要求された識別子の解決にのみ使用してください。メトリクスを比較する前に、返された製品/バリアントがタスクと一致していることを確認してください。

`products extract` はソース URL を受け取り、外部データを取得する場合があります。 1 つのアイテムのみが必要な場合に、カタログ全体に対して実行しないでください。属性を変更する前に現在の属性キーを読み取り、無関係な値を保持し、更新された ID を検証してください。
