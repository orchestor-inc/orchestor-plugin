# ショッピングレポートの選択

| 質問 | レポートファミリー |
| --- | --- |
| 製品はどのくらいの頻度で、どこに表示されるか？ | shopping-performance |
| どのような需要シグナルが示されているか？ | shopping-demand |
| 系列は時間の経過とともにどのように変化するか？ | shopping-trend |
| どのマーチャントが表示されるか？ | merchants |

各リーフでサポートされているメトリクス/ディメンションを確認してください。ショッピングメトリクスには、サポートされている場合、 rendered_visibility 、 appearances 、 average_position 、および win_rate が含まれます。これらはブランド言及のメトリクスと相互に代替できません。

**誤り:** 表示（appearance）を購入と呼ぶこと、互換性のないグループ間で平均を合算すること、またはマーチャントのリスティングと製品ファミリーの集計を比較すること。

**正しい対応:** 製品アイデンティティ、期間、チャネル、国、プロンプトコホート、および返された分母を保持してください。裏付けとなるエビデンスを検査し、欠落しているデータを説明してください。需要シグナルは観察された売上ではありません。ソースのカバレッジと収集時刻が重要です。
