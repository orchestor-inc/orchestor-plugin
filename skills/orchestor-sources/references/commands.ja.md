# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03 、 CLI ソースバージョン 0.6.2 。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングカバレッジを証明するものであり、認証された実行や公開されたすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を確認してください。

| コマンド | 目的 |
| --- | --- |
| `orc fanout-queries list` | ファンアウトクエリカタログの一覧表示 |
| `orc sources citations list` | ソース引用集計の一覧表示 |
| `orc sources domains get` | ソースドメイン詳細の取得 |
| `orc sources domains list` | ソースドメインの一覧表示 |
| `orc sources gaps list` | ローカルで導出されたソースギャップの一覧表示 |
| `orc sources urls get` | ソース URL 詳細の取得 |
| `orc sources urls list` | ソース URL の一覧表示 |
