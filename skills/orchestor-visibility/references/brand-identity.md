# Brand and competitor identity

Read existing brands before adding or updating them. Match the intended brand
by ID and confirmed website/name; do not create duplicates to resolve a spelling
variation. A workspace may contain several brands and competitors.

Use the brands, suggestions, and domains command families for the requested
change. Suggestions are candidates, not verified facts. Accept or reject only
the specified suggestions and read back the resulting records.

Before merging an update, inspect the field behavior. An omitted array may retain
its value, while a supplied array may replace it. Preserve unrelated aliases,
competitors, or metadata. Domain ownership verification is a separate operation;
a stored domain record alone does not prove ownership or data collection.
