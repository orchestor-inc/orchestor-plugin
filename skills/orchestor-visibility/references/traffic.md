# Interpret bots and referrals

Bot/crawler requests, referral clicks, search results, brand mentions, and
citations measure different events. Do not substitute one for another.

Inspect the connected source, reporting period, and data availability before
using bots or referrals as corroborating evidence. A missing connection or
unavailable period is unknown coverage, not zero visits.

Report observed traffic and its source. Do not infer that a particular citation
caused a visit unless the returned evidence supports that connection. Use
`orchestor-integrations` for an explicitly requested connection change; a report
request does not authorize creating provider properties or access grants.
