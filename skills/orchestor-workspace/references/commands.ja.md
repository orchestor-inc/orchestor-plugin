# CLI コマンドリファレンス

カタログスナップショット: 2026-10-03、CLI ソースバージョン 0.6.2。これらの名前は公開 CLI レジストリに対して解決されました。これはルーティングのカバレッジを証明するものであり、認証済みの実行や公開されているすべてのバイナリでの利用可能性を証明するものではありません。引数、スキーマ、権限、および制限については、インストールされているリーフコマンドの `--help` を参照してください。

| コマンド | 目的 |
| --- | --- |
| `orc feedbacks create` | 製品フィードバックまたはバグレポートを送信する |
| `orc feedbacks list` | オーナーの読み戻し用に顧客フィードバックを一覧表示する |
| `orc files create` | ファイルをアップロードする |
| `orc files get` | ファイルのメタデータを取得する |
| `orc files list` | アップロードされたファイルを一覧表示する |
| `orc files content get` | ファイルのバイナリコンテンツをダウンロードする |
| `orc files content update` | ファイルのバイナリコンテンツをアップロードする |
| `orc initiatives activity list` | イニシアチブのアクティビティを一覧表示する |
| `orc initiatives batch update` | イニシアチブを一括更新する |
| `orc initiatives comments create` | イニシアチブにコメントする |
| `orc initiatives comments list` | イニシアチブのコメントを一覧表示する |
| `orc initiatives create` | ワークスペースのイニシアチブを作成する |
| `orc initiatives delete` | イニシアチブを論理削除する |
| `orc initiatives favorites disable` | イニシアチブのお気に入りを解除する |
| `orc initiatives favorites enable` | イニシアチブをお気に入りに追加する |
| `orc initiatives get` | イニシアチブを取得する |
| `orc initiatives list` | ワークスペースのイニシアチブを一覧表示する |
| `orc initiatives projects create` | イニシアチブにプロジェクトを追加する |
| `orc initiatives projects delete` | イニシアチブからプロジェクトを削除する |
| `orc initiatives projects list` | イニシアチブのプロジェクトを一覧表示する |
| `orc initiatives projects update` | イニシアチブのプロジェクトの順序を変更する |
| `orc initiatives restore` | イニシアチブを復元する |
| `orc initiatives rollup get` | イニシアチブの進捗ロールアップを取得する |
| `orc initiatives subscriptions disable` | イニシアチブの購読を解除する |
| `orc initiatives subscriptions enable` | イニシアチブを購読する |
| `orc initiatives update` | イニシアチブを更新する |
| `orc initiatives updates create` | イニシアチブの更新情報を投稿する |
| `orc initiatives updates list` | イニシアチブの更新情報を一覧表示する |
| `orc project-label-groups create` | 相互排他的なプロジェクトラベルグループを作成する |
| `orc project-label-groups delete` | ワークスペースのプロジェクトラベルグループを削除する |
| `orc project-label-groups list` | ワークスペースのプロジェクトラベルグループを一覧表示する |
| `orc project-label-groups update` | ワークスペースのプロジェクトラベルグループを更新する |
| `orc projects archive` | プロジェクトをアーカイブする |
| `orc projects create` | プロジェクトを作成する |
| `orc projects get` | プロジェクトを取得する |
| `orc projects list` | プロジェクトを一覧表示する |
| `orc projects milestones create` | プロジェクトのマイルストーンを作成する |
| `orc projects milestones delete` | プロジェクトのマイルストーンを削除する |
| `orc projects milestones issues delete` | マイルストーンからイシューを削除する |
| `orc projects milestones issues update` | イシューをマイルストーンに割り当てる |
| `orc projects milestones list` | プロジェクトのマイルストーンを一覧表示する |
| `orc projects milestones order update` | プロジェクト内のすべてのマイルストーンの順序を変更する |
| `orc projects milestones update` | プロジェクトのマイルストーンを更新する |
| `orc projects restore` | アーカイブされたプロジェクトを復元する |
| `orc projects rollup get` | プロジェクトの進捗ロールアップを取得する |
| `orc projects update` | プロジェクトを更新する |
| `orc saved-views create` | 名前付きクエリフィルタービューを保存する |
| `orc saved-views list` | 保存されたクエリフィルタービューを一覧表示する |
| `orc workspaces archive` | ワークスペースをアーカイブする |
| `orc workspaces create` | ワークスペースを作成する |
| `orc workspaces get` | ワークスペースを取得する |
| `orc workspaces list` | ワークスペースを一覧表示する |
| `orc workspaces members create` | ワークスペースメンバーを追加する |
| `orc workspaces members delete` | ワークスペースメンバーを削除する |
| `orc workspaces members list` | ワークスペースメンバーを一覧表示する |
| `orc workspaces pause` | ワークスペースの測定を一時停止する |
| `orc workspaces restore` | ワークスペースを復元する |
| `orc workspaces resume` | ワークスペースの測定を再開する |
| `orc workspaces update` | ワークスペースを更新する |
