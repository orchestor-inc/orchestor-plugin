# CLI command reference

Catalog snapshot: 2026-10-03, CLI source version 0.6.2. These names were
resolved against the public CLI registry. This proves routing coverage, not
authenticated execution or availability in every published binary. Read the
installed leaf command’s `--help` for arguments, schema, permissions and limits.

| Command | Purpose |
| --- | --- |
| `orc feedbacks create` | Submit product feedback or bug report |
| `orc feedbacks list` | List customer feedback for owner readback |
| `orc files create` | Upload a file |
| `orc files get` | Retrieve file metadata |
| `orc files list` | List uploaded files |
| `orc files content get` | Download file binary content |
| `orc files content update` | Upload file binary content |
| `orc initiatives activity list` | List Initiative activity |
| `orc initiatives batch update` | Batch update Initiatives |
| `orc initiatives comments create` | Comment on an Initiative |
| `orc initiatives comments list` | List Initiative comments |
| `orc initiatives create` | Create a workspace initiative |
| `orc initiatives delete` | Soft-delete an Initiative |
| `orc initiatives favorites disable` | Unfavorite an Initiative |
| `orc initiatives favorites enable` | Favorite an Initiative |
| `orc initiatives get` | Get an initiative |
| `orc initiatives list` | List workspace initiatives |
| `orc initiatives projects create` | Add a Project to an Initiative |
| `orc initiatives projects delete` | Remove a Project from an Initiative |
| `orc initiatives projects list` | List Initiative Projects |
| `orc initiatives projects update` | Reorder an Initiative Project |
| `orc initiatives restore` | Restore an Initiative |
| `orc initiatives rollup get` | Get initiative progress rollup |
| `orc initiatives subscriptions disable` | Unsubscribe from an Initiative |
| `orc initiatives subscriptions enable` | Subscribe to an Initiative |
| `orc initiatives update` | Update an initiative |
| `orc initiatives updates create` | Post an Initiative Update |
| `orc initiatives updates list` | List Initiative Updates |
| `orc project-label-groups create` | Create a mutually exclusive project label group |
| `orc project-label-groups delete` | Delete a workspace project label group |
| `orc project-label-groups list` | List workspace project label groups |
| `orc project-label-groups update` | Update a workspace project label group |
| `orc projects archive` | Archive project |
| `orc projects create` | Create project |
| `orc projects get` | Get project |
| `orc projects list` | List projects |
| `orc projects milestones create` | Create a project milestone |
| `orc projects milestones delete` | Delete a project milestone |
| `orc projects milestones issues delete` | Remove an Issue from a milestone |
| `orc projects milestones issues update` | Assign an Issue to a milestone |
| `orc projects milestones list` | List project milestones |
| `orc projects milestones order update` | Reorder every milestone in a project |
| `orc projects milestones update` | Update a project milestone |
| `orc projects restore` | Restore an archived project |
| `orc projects rollup get` | Get Project progress rollup |
| `orc projects update` | Update project |
| `orc saved-views create` | Save a named query-filter view |
| `orc saved-views list` | List saved query-filter views |
| `orc workspaces archive` | Archive workspace |
| `orc workspaces create` | Create workspace |
| `orc workspaces get` | Get workspace |
| `orc workspaces list` | List workspaces |
| `orc workspaces members create` | Add workspace member |
| `orc workspaces members delete` | Remove workspace member |
| `orc workspaces members list` | List workspace members |
| `orc workspaces pause` | Pause workspace measurement |
| `orc workspaces restore` | Restore workspace |
| `orc workspaces resume` | Resume workspace measurement |
| `orc workspaces update` | Update workspace |
