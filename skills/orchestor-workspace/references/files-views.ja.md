# ファイルと保存されたビュー

ファイルの登録レスポンスは、バイト列がアップロードされたことの証明にはなりません。目的、ファイル名、MIME タイプ、想定バイトサイズ、および返されたアップロード手順を含め、現在のアップロード／コンテンツ規約を確認してください。ファイルまたはコンテンツのレシートを読み戻してください。

**誤り:** メタデータを作成しただけでドキュメントが添付されたと報告することや、公開配布されるスキルディレクトリ配下に顧客のエクスポートデータを保存すること。

**正しい対応:** 対象のワークスペースと明示的な目的／オーナー参照を使用し、サポートされている転送を完了した上で、生成された ID と添付ファイルを検証すること。規約で要求されている場合、イシューの添付ファイルにはイシューオーナー参照を使用します。失敗した転送をデバッグするために、署名付きアップロード URL をログに記録したり、プライベートなコンテンツを公開したりしないでください。

保存されたビューは、要求されたフィルター／整理状態をキャプチャするものです。これらは測定スケジュールやエビデンスのスナップショットではありません。デフォルトビューの変更が明示的に要求されていない限り、既存のデフォルト設定を維持してください。
