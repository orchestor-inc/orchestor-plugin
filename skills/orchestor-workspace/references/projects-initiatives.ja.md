# プロジェクト、マイルストーン、およびイニシアチブ

イシューの project_id は UUID です。マイルストーンコマンドは、位置識別子として projectKey を受け取ることができます。そのキーは `projects list` またはプロジェクトレコードから解決してください。単に双方が同じプロジェクトを識別しているからという理由で、UUID で代用してはなりません。

**誤り:** キー検索で誤った識別子を使用したために新しいプロジェクトを作成することや、マイルストーンが指定されたプロジェクトに属していることを確認せずにイシューをマイルストーンに割り当てること。

**正しい対応:** プロジェクトの UUID と projectKey を個別に保持すること。選択されたプロジェクトのマイルストーンを一覧表示し、指定されたマイルストーン ID を照合した上で、要求された関係の変更を実行すること。名前のみが指定されており複数の候補が一致して残っている場合は、推測するのではなくその選択を求めてください。

イニシアチブのロールアップとプロジェクトのロールアップは、それぞれのスコープを集約するものです。これらは元のイシューのエビデンスを置き換えるものではありません。更新情報、コメント、購読、お気に入り、およびプロジェクトの関連付けは明確に区別してください。整理の要求は、コメントを投稿したり他者を購読させたりする権限を付与するものではありません。
