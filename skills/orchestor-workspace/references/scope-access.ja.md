# スコープとメンバーシップ

ローカルの `workspace use/link` の選択とリモートワークスペースの変更は異なる操作です。アクティブな接続を確認し、クライアントをまたいで作業する際は、データ呼び出し時に明示的に `--workspace` を渡してください。

**誤り:** プロジェクト名が同じであるという理由で 2 つの顧客の回答を 1 つの分析に混同することや、無関係な読み取り権限エラーを解決するためにワークスペースメンバーを追加すること。

**正しい対応:** ワークスペースごとに個別のスコープとエビデンスセットを保持すること。明示的なメンバーシップ要求に対しては、対象となるメンバー、ワークスペース、およびロールを確認し、最初に既存のメンバーシップを調査した上で、その変更のみを適用して検証すること。

リソースのアーカイブ、復元、一時停止、再開、および削除には異なるセマンティクスがあります。ある操作から別の操作を推測しないでください。現在の状態と関連するヘルプを確認し、設定の要求をより広範なライフサイクル操作に拡張しないでください。
